# 直播管理模块功能说明

## 一、模块概述

直播管理模块是LiveHouse系统的核心功能之一，主要用于管理楼盘直播场次和白名单权限控制。本模块实现了完整的CRUD功能以及开播/关播操作。

## 三、技术特点

### 3.1 后端技术
- **MyBatis-Plus** - 使用Lambda表达式进行条件查询，无需编写SQL
- **统一返回格式** - 使用Result封装响应数据
- **分页支持** - 使用PageHelper实现分页查询
- **逻辑删除** - 使用@TableLogic注解实现软删除
- **自动填充** - 使用@TableField(fill = FieldFill)自动填充创建/更新时间

### 3.2 前端技术
- **Vue 3 Composition API** - 使用setup语法糖
- **Element Plus** - 使用现代化UI组件
- **响应式设计** - 使用ref和reactive管理状态
- **异步处理** - 使用async/await处理API调用
- **错误处理** - 完善的try-catch和用户提示

## 四、数据库表结构

### 4.1 live_session（直播场次表）
主要字段：
- id - 主键
- session_name - 场次名称
- session_code - 场次编码（自动生成）
- live_type - 直播类型（1-公开 2-VIP私密）
- anchor_id - 主播ID
- anchor_name - 主播名称
- password - 观看密码（私密直播）
- start_time - 计划开始时间
- end_time - 计划结束时间
- actual_start_time - 实际开始时间
- actual_end_time - 实际结束时间
- status - 状态（0-未开始 1-直播中 2-已结束 3-已关闭）
- introduction - 直播简介

### 4.2 live_whitelist（直播白名单表）
主要字段：
- id - 主键
- session_id - 直播场次ID
- phone - 手机号
- customer_name - 客户姓名
- remark - 备注

## 五、业务流程

### 5.1 创建直播场次流程
1. 管理员填写直播信息（名称、类型、主播、时间等）
2. 系统自动生成场次编码
3. 保存到数据库，初始状态为"未开始"
4. 如果是VIP私密直播，需要设置观看密码

### 5.2 开播流程
1. 管理员点击"开始直播"按钮
2. 系统校验当前状态是否为"未开始"
3. 更新状态为"直播中"
4. 记录实际开始时间
5. 刷新列表显示最新状态

### 5.3 关播流程
1. 管理员点击"结束直播"按钮
2. 系统校验当前状态是否为"直播中"
3. 更新状态为"已结束"
4. 记录实际结束时间
5. 刷新列表显示最新状态

### 5.4 添加白名单流程
1. 管理员选择直播场次
2. 从客户管理模块的客户列表中选择客户
3. 系统带出客户姓名和手机号
4. 系统验证手机号格式并检查该手机号是否已在白名单中
5. 如果不存在则添加，否则提示重复
6. 保存成功后刷新列表

### 5.5 批量导入白名单流程
1. 管理员选择直播场次
2. 从客户管理模块的客户列表中批量选择客户
3. 系统逐个校验手机号、重复数据和场次有效性
4. 有效客户写入白名单
5. 返回成功、重复、无效统计和错误明细

## 六、接口示例

```json

{
  "sessionName": "翡翠湾新品发布会",
```
