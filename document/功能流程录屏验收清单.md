# LiveHouse 功能流程录屏验收清单

> 用途：用于交付验收、功能演示录屏、测试人员按步骤复现业务闭环。
> 建议录屏方式：桌面端浏览器打开管理后台，移动端尺寸或另一个浏览器窗口打开 H5 用户端。

## 一、录屏前准备

- [ ] 后端服务已启动，接口可正常访问。
- [ ] 管理后台已启动并可访问。
- [ ] H5 用户端已启动并可访问。
- [ ] 数据库已完成初始化脚本导入，至少存在楼盘、户型、直播、客户、预约等测试数据。
- [ ] 准备后台管理员账号：`admin / admin123`。
- [ ] 准备 H5 测试用户账号；如无账号，录屏时走注册流程。
- [ ] 准备一张楼盘封面图、一张户型图或 VR 缩略图，用于演示上传/展示。
- [ ] 如直播依赖第三方真实推拉流，提前确认腾讯云直播配置；如为演示环境，可说明使用模拟播放地址。

## 二、后台端主流程

### 1. 管理员登录与首页看板

- [ ] 打开管理后台登录页。
- [ ] 输入管理员账号密码并登录。
- [ ] 进入数据看板页。
- [ ] 验证页面可展示核心指标、趋势数据或业务统计卡片。
- [ ] 验证左侧菜单可正常展开：系统管理、房源管理、直播管理、客户管理、消息中心、数据看板。

验收结果：管理员可登录，菜单与看板加载正常。

### 2. 系统权限与首页配置

- [ ] 进入“系统管理 / 用户管理”，查看员工账号列表。
- [ ] 新增或编辑一个员工账号，选择角色并保存。
- [ ] 进入“角色管理”，查看角色列表和角色状态。
- [ ] 进入“菜单管理”，验证菜单树、路由、权限标识可展示。
- [ ] 进入“首页配置”，配置 H5 首页 banner、推荐楼盘或直播入口。
- [ ] 保存首页配置后，切换到 H5 首页验证展示效果。

验收结果：后台具备账号、角色、菜单和 H5 首页内容配置能力。

### 3. 楼盘与户型管理

- [ ] 进入“房源管理 / 楼盘管理”。
- [ ] 新增楼盘，填写楼盘名称、区域、地址、价格、开发商、物业、楼盘简介等信息。
- [ ] 上传或填写楼盘封面图。
- [ ] 保存后在楼盘列表中搜索该楼盘。
- [ ] 编辑楼盘信息，修改价格或简介并保存。
- [ ] 进入“户型管理”，新增户型并绑定刚才的楼盘。
- [ ] 填写户型名称、室厅卫、面积、总价、朝向、户型说明等信息。
- [ ] 保存后验证户型列表可按楼盘或关键字筛选。

验收结果：楼盘和户型可新增、编辑、查询，并能作为 H5 展示和预约的基础数据。

### 4. VR 看房配置

- [ ] 进入“房源管理 / VR 管理”。
- [ ] 新增 VR 看房记录，绑定楼盘和户型。
- [ ] 配置 VR 名称、缩略图、全景图或场景素材。
- [ ] 配置场景、热点、跳转目标或讲解信息。
- [ ] 保存后点击预览或打开 H5 VR 页面。
- [ ] 在 H5 VR 页面验证可拖拽/旋转查看，全景画面、热点、场景切换正常。

验收结果：后台可维护 VR 素材，H5 可沉浸式查看 VR 房源。

### 5. 直播平台与直播场次

- [ ] 进入“直播管理 / 直播平台”。
- [ ] 查看腾讯云、阿里云或其他平台配置。
- [ ] 新增或编辑一个直播平台配置，确认平台名称、平台编码、推流/播放域名等字段可保存。
- [ ] 进入“直播管理 / 直播场次”。
- [ ] 新增直播场次，绑定楼盘、户型、主播、直播封面、开始时间、直播简介。
- [ ] 选择公开直播并保存。
- [ ] 查看直播场次列表，确认状态为未开始。
- [ ] 点击开始直播，验证系统生成或展示推流地址、播放地址。
- [ ] 如弹出开播通知窗口，选择客户并发送站内信或短信通知。
- [ ] 结束直播，验证直播状态变为已结束。

验收结果：直播场次可创建、开播、通知、结束，并与楼盘客户数据关联。

### 6. 私密直播与白名单

- [ ] 新建或编辑一场直播，将直播类型设置为私密。
- [ ] 设置观看密码。
- [ ] 进入“直播管理 / 白名单管理”。
- [ ] 为该直播场次新增客户手机号白名单。
- [ ] 可选：使用批量导入方式导入多个手机号。
- [ ] 在 H5 打开该私密直播，使用非白名单手机号或错误密码访问，验证无法进入。
- [ ] 使用白名单手机号和正确密码访问，验证可进入直播详情。

验收结果：私密直播支持密码和手机号白名单控制。

### 7. 消息模板、站内信与短信记录

- [ ] 进入“消息中心 / 消息模板”。
- [ ] 查看或编辑直播开播提醒模板，例如 `LIVE_START`。
- [ ] 回到直播场次，触发开播通知。
- [ ] 进入“消息中心 / 消息管理”，验证生成站内信记录。
- [ ] 进入“消息中心 / 短信记录”，验证短信发送记录或 mock 记录生成。
- [ ] 在 H5 用户端进入消息中心，验证用户可收到并查看消息。

验收结果：模板配置、开播通知、站内信、短信记录链路可闭环验证。

### 8. 客户、预约与跟进

- [ ] 进入“客户管理 / 客户列表”。
- [ ] 查看由预约或直播留资沉淀的客户数据。
- [ ] 新增或编辑客户信息，补充客户等级、意向状态、预算、意向户型等。
- [ ] 进入“预约管理”，查看 H5 提交的看房预约。
- [ ] 修改预约状态，例如待确认、已确认、已到访或取消。
- [ ] 进入“跟进记录”，新增客户跟进记录。
- [ ] 填写跟进方式、跟进内容、意向等级、下次跟进时间。
- [ ] 返回客户列表，验证客户跟进次数、最近跟进时间或状态变化。

验收结果：H5 线索可进入后台客户池，并支持预约管理和销售跟进。

## 三、H5 用户端主流程

### 1. 首页与楼盘浏览

- [ ] 打开 H5 用户端首页。
- [ ] 验证 banner、推荐楼盘、直播入口、功能入口正常展示。
- [ ] 进入楼盘列表。
- [ ] 使用筛选或搜索查看楼盘。
- [ ] 进入楼盘详情页。
- [ ] 验证楼盘封面、价格、区域、简介、户型列表等内容展示正常。
- [ ] 点击收藏楼盘。
- [ ] 返回“我的 / 收藏”，验证收藏记录存在。
- [ ] 返回“我的 / 浏览历史”，验证浏览记录存在。

验收结果：用户可完成首页浏览、楼盘查看、收藏和历史记录沉淀。

### 2. 用户注册登录与个人中心

- [ ] 进入注册页，填写手机号、用户名、密码并注册。
- [ ] 使用注册账号登录。
- [ ] 进入个人中心。
- [ ] 查看我的预约、消息、收藏、浏览历史、设置等入口。
- [ ] 进入设置页，切换消息通知、短信通知、浏览历史等开关。

验收结果：H5 用户账号体系和个人中心功能可用。

### 3. VR 看房体验

- [ ] 从楼盘详情或 VR 入口进入 VR 看房页面。
- [ ] 验证全景图正常加载。
- [ ] 拖动画面查看不同方向。
- [ ] 点击热点切换场景或查看说明。
- [ ] 如配置了解说文案或音频，验证可展示或播放。
- [ ] 返回楼盘详情。

验收结果：H5 支持移动端 VR 看房体验。

### 4. 看房预约

- [ ] 在楼盘详情点击预约看房。
- [ ] 填写姓名、手机号、预约时间、到访方式或备注。
- [ ] 提交预约。
- [ ] 验证页面提示提交成功。
- [ ] 进入“我的预约”，确认预约记录存在。
- [ ] 切换后台“预约管理”，确认同一条预约记录已同步生成。

验收结果：H5 预约提交后，后台可管理该预约。

### 5. 直播列表与直播观看

- [ ] 进入 H5 直播列表。
- [ ] 查看未开始、直播中、已结束等直播状态。
- [ ] 进入公开直播详情页。
- [ ] 验证直播封面、标题、主播、楼盘信息、简介、开始时间展示正常。
- [ ] 开播状态下验证播放器区域或播放地址加载正常。
- [ ] 点击点赞。
- [ ] 发送弹幕或留言。
- [ ] 验证互动区点赞数、弹幕内容或互动列表刷新。
- [ ] 点击直播间预约或留资入口，提交看房意向。
- [ ] 后台客户列表和预约管理中验证数据沉淀。

验收结果：直播观看、互动、留资和后台沉淀链路可用。

### 6. 私密直播访问验证

- [ ] 打开私密直播详情页。
- [ ] 未登录或未授权时验证提示登录、输入密码或手机号校验。
- [ ] 输入错误密码，验证无法进入。
- [ ] 输入正确密码和白名单手机号，验证进入直播详情。
- [ ] 如该手机号不在白名单，验证系统提示无权限。

验收结果：私密直播访问控制生效。

### 7. 消息中心

- [ ] 进入 H5 消息中心。
- [ ] 查看开播提醒、预约通知或系统通知。
- [ ] 点击消息查看详情。
- [ ] 标记单条消息为已读。
- [ ] 使用全部已读功能。
- [ ] 删除一条消息，验证列表同步更新。

验收结果：用户可接收、阅读、批量已读和删除消息。

## 四、端到端闭环录屏推荐脚本

1. 后台登录，展示数据看板和菜单结构。
2. 后台新增楼盘、户型、VR 素材。
3. H5 首页查看新配置的楼盘，进入详情并收藏。
4. H5 进入 VR 看房，展示拖拽、热点、场景切换。
5. H5 提交看房预约。
6. 后台预约管理查看并确认该预约。
7. 后台客户列表查看客户沉淀，并新增跟进记录。
8. 后台创建直播场次，配置公开直播或私密直播。
9. 后台开始直播并发送开播通知。
10. H5 消息中心查看开播通知，点击进入直播详情。
11. H5 直播间点赞、发送弹幕、提交预约/留资。
12. 后台直播管理结束直播。
13. 后台消息管理、短信记录、客户管理、预约管理分别验证本次操作数据。
14. 后台数据看板查看统计变化，作为最终收口画面。

## 五、补充验收点

- [ ] 未登录后台访问管理页会跳转登录页。
- [ ] H5 未登录访问个人中心、我的预约、消息等页面时，有登录引导。
- [ ] 表单必填项为空时有明确校验提示。
- [ ] 列表支持分页、搜索、刷新。
- [ ] 上传图片后，后台列表和 H5 页面均能正常展示。
- [ ] 删除或禁用数据后，前台不展示异常内容。
- [ ] 私密楼盘、私密 VR 或私密直播不会被未授权用户直接查看。
- [ ] 开播通知模板变量能正确替换直播名称、主播、时间、链接、客户姓名。
- [ ] 移动端页面在常见手机宽度下不出现明显遮挡、横向滚动或按钮不可点。

## 六、录屏交付建议

- [ ] 录屏开始先展示系统名称和两个入口：管理后台、H5 用户端。
- [ ] 每个功能点停留 3 到 5 秒，确保操作结果清晰可见。
- [ ] 涉及新增数据时，统一使用带日期或“演示”字样的名称，便于后续检索。
- [ ] 涉及手机号、客户姓名时，使用测试数据，避免真实隐私信息出镜。
- [ ] 如第三方直播未接真实推流，可在录屏旁白中说明“当前演示环境使用模拟播放地址，生产环境接腾讯云直播推拉流”。
- [ ] 录屏结尾回到后台数据看板或客户/预约列表，展示业务数据已经完成沉淀。
