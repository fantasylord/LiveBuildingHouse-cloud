## 1. 项目概述

### 1.1 项目背景

本系统为高端楼盘专属智慧营销系统，聚焦别墅、大平层、顶奢住宅场景，整合线下VR智慧看房、线上云直播带看、客户精细化CRM运营能力。

### 1.2 项目定位

- 采用轻量化单体架构
- 适配1-3人小团队开发交付
- 摒弃复杂架构与冗余功能
- 核心差异化能力：隐私管控、沉浸式看房、私密直播

### 1.3 核心业务场景

#### 线下场景
- 用户线上预约看房
- 案场到访登记
- 720°VR全景看房
- 顾问带看记录留存

#### 线上场景
- 公开楼盘直播
- VIP私密密码/白名单直播
- 直播在线留资
- 意向客户预约看房

#### 运营场景
- 房源楼盘管理
- 私密房源权限管控
- 客户档案管理
- 简易数据统计
- 员工权限分级

### 1.4 项目设计原则

| 原则 | 说明 |
|------|------|
| 轻量化 | 单体架构、模块精简、中间件最少化 |
| 低风险 | 核心音视频能力依托三方云服务 |
| 保核心 | 完整保留隐私隔离、VR沉浸式看房、私密直播 |
| 可验收 | 所有功能标准化、可量化 |
| 易迭代 | 基础版本稳定，可按需扩展 |

**配置说明**：

1. **访问密钥获取**：
   - 路径：腾讯云控制台 → 访问密钥 → API密钥管理
   - 复制 `SecretId` 和 `SecretKey`

2. **域名配置**：
   - 路径：腾讯云控制台 → 直播 → 域名管理
   - 添加推流域名（如：`push.livehouse.com`）
   - 添加播放域名（如：`play.livehouse.com`）
   - 域名必须完成 ICP 备案

3. **应用配置**：
   - 默认应用名为 `live`
   - 在域名管理 → 访问配置中配置鉴权密钥

4. **配置示例**：
```yaml
tencent:
  cloud:
    enabled: true
    secret-id: AKIDxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    secret-key: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    live-region: ap-shanghai
    push-domain: push.livehouse.com
    play-domain: play.livehouse.com
    app-name: live
    push-expire-time: 3600
    play-expire-time: 86400
    enable-anti-leech: true
```

5. **地址格式**：
   - 推流地址：`rtmp://推流域名/应用名/流名?txSecret=xxx&txTime=xxx`
   - 播放地址（HLS）：`https://播放域名/应用名/流名.m3u8?txSecret=xxx&txTime=xxx`
   - 播放地址（FLV）：`https://播放域名/应用名/流名.flv?txSecret=xxx&txTime=xxx`

## 3. 数据库设计

### 3.1 数据库命名规范

- 库名：`livehouse`
- 表名：采用 `sys_`、`house_`、`live_`、`customer_` 前缀
- 字段名：snake_case 命名
- 索引命名：`idx_字段名`

#### 3.1.1 字段命名规范（MyBatis-Plus适配）

| 字段类型 | 字段名 | 类型 | 默认值 | 说明 |
|----------|--------|------|--------|------|
| 主键 | id | BIGINT | 自增 | 主键ID |
| 创建时间 | create_time | DATETIME | CURRENT_TIMESTAMP | 创建时间 |
| 更新时间 | update_time | DATETIME | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |
| 创建人 | create_by | BIGINT | - | 创建人ID |
| 更新人 | update_by | BIGINT | - | 更新人ID |
| 逻辑删除 | deleted | TINYINT | 0 | 删除标记: 0-未删 1-已删 |
| 排序字段 | sort_order | INT | 0 | 排序值 |
| 状态 | status | TINYINT | 1 | 状态标识 |
| 备注 | remark | VARCHAR(500) | - | 备注信息 |

**注意：** MyBatis-Plus 使用 `@TableLogic` 注解配合 `deleted` 字段实现逻辑删除。

```sql
CREATE TABLE sys_user (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    username        VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password        VARCHAR(100) NOT NULL COMMENT '密码',
    real_name       VARCHAR(50) COMMENT '真实姓名',
    phone           VARCHAR(20) COMMENT '手机号',
    email           VARCHAR(100) COMMENT '邮箱',
    avatar          VARCHAR(255) COMMENT '头像URL',
    role_id         BIGINT NOT NULL COMMENT '角色ID',

    last_login_time DATETIME COMMENT '最后登录时间',
    last_login_ip   VARCHAR(50) COMMENT '最后登录IP',
    remark          VARCHAR(500) COMMENT '备注',
    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time     DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    create_by       BIGINT COMMENT '创建人',
```

**SQL调整说明：**

- 当前数据库已存在 `hotspots` 与 `scenes` JSON 字段，场景化 VR 不需要新增独立场景表；业务热点统一配置在 `scenes.scenes[].hotspots`。
- 设计文档字段名以当前代码实体 `HouseVr` 和初始化脚本为准：楼盘字段使用 `building_id`，私密字段使用 `privated`。
- 如历史环境缺少 `scenes` 字段，可执行：

```sql
ALTER TABLE house_vr
    ADD COLUMN scenes JSON COMMENT '场景化VR配置，包含场景列表、户型模型图、热点目标场景等' AFTER hotspots;
```

### 5.2 直播模块

#### 5.2.1 三方直播平台对接流程

```
1. 后台配置三方直播平台
   ↓
2. 创建直播场次时选择三方平台
   ↓
3. 根据平台配置生成推拉流地址
   ↓
4. 主播使用推流工具开播
   ↓
5. 用户通过H5观看直播
   ↓
6. 直播结束自动生成回放
```

#### 5.2.2 三方直播地址生成服务

```java
@Service
public class LiveAddressService {
    
    /**
     * 根据平台类型生成直播地址
     */
    public LiveAddress generateLiveAddress(LivePlatform platform, String streamId, Integer expireTime) {
        switch (platform.getPlatformType()) {
            case "tencent":
                return generateTencentAddress(platform, streamId, expireTime);
            case "aliyun":
                return generateAliyunAddress(platform, streamId, expireTime);
            case "douyin":
                return generateDouyinAddress(platform, streamId, expireTime);
            default:
                throw new BusinessException("不支持的平台类型");
        }
    }
    
    /**
     * 生成腾讯云直播地址
     */
    private LiveAddress generateTencentAddress(LivePlatform platform, String streamId, Integer expireTime) {
        // 生成推流地址
        String pushUrl = String.format("rtmp://%s/live/%s?sign=%s",
            platform.getPushDomain(),
            streamId,
```

```javascript
// 场景切换管理
class VRSceneManager {
  constructor() {
    this.currentSceneId = null;
    this.scenes = new Map(); // 场景缓存
    this.preloadQueue = []; // 预加载队列
  }

  // 切换场景
  async switchScene(sceneId) {
    // 1. 显示加载动画
    this.showLoading();

    // 2. 获取场景数据
    const sceneData = await this.fetchSceneData(sceneId);

    // 3. 清除当前场景
    this.clearCurrentScene();

    // 4. 加载新场景全景图
    const texture = await this.loadTexture(sceneData.panoramaUrl);

    // 5. 创建新场景
    this.createScene(texture, sceneData.hotspots);

    // 6. 更新当前场景ID
    this.currentSceneId = sceneId;

    // 7. 预加载相邻场景
    this.preloadAdjacentScenes(sceneData.adjacentScenes);

    // 8. 隐藏加载动画
    this.hideLoading();
  }

  // 预加载相邻场景
  preloadAdjacentScenes(sceneIds) {
    sceneIds.forEach(id => {
      if (!this.scenes.has(id)) {
        this.preloadQueue.push(id);
      }
    });
    this.processPreloadQueue();
  }

  // 处理预加载队列
  async processPreloadQueue() {
    while (this.preloadQueue.length > 0) {
      const sceneId = this.preloadQueue.shift();
      const sceneData = await this.fetchSceneData(sceneId);
      const texture = await this.loadTexture(sceneData.panoramaUrl);
      this.scenes.set(sceneId, { texture, hotspots: sceneData.hotspots });
    }
  }
}
```

```javascript
class GestureController {
  constructor(camera, renderer) {
    this.camera = camera;
    this.renderer = renderer;
    this.isDragging = false;
    this.previousTouch = { x: 0, y: 0 };
    this.rotationSpeed = 0.005;

    this.initEvents();
  }

  initEvents() {
    const canvas = this.renderer.domElement;

    // 触摸开始
    canvas.addEventListener('touchstart', (e) => {
      if (e.touches.length === 1) {
        this.isDragging = true;
        this.previousTouch = {
          x: e.touches[0].clientX,
          y: e.touches[0].clientY
        };
      }
    });

    // 触摸移动
    canvas.addEventListener('touchmove', (e) => {
      if (this.isDragging && e.touches.length === 1) {
        const touch = e.touches[0];
        const deltaX = touch.clientX - this.previousTouch.x;
        const deltaY = touch.clientY - this.previousTouch.y;

        // 更新相机旋转
        this.camera.rotation.y -= deltaX * this.rotationSpeed;
        this.camera.rotation.x -= deltaY * this.rotationSpeed;

        // 限制垂直旋转角度
        this.camera.rotation.x = Math.max(
          -Math.PI / 2,
          Math.min(Math.PI / 2, this.camera.rotation.x)
        );

        this.previousTouch = { x: touch.clientX, y: touch.clientY };
      }
    });

    // 触摸结束
    canvas.addEventListener('touchend', () => {
      this.isDragging = false;
    });
  }
}

class GyroscopeController {
  constructor(camera) {
    this.camera = camera;
    this.enabled = false;
    this.deviceOrientation = { alpha: 0, beta: 0, gamma: 0 };
  }

  enable() {
    if (typeof DeviceOrientationEvent !== 'undefined') {
      // iOS 13+ 需要请求权限
      if (typeof DeviceOrientationEvent.requestPermission === 'function') {
        DeviceOrientationEvent.requestPermission()
          .then(response => {
            if (response === 'granted') {
              this.enabled = true;
              window.addEventListener('deviceorientation', this.onDeviceOrientation);
            }
          });
      } else {
        this.enabled = true;
        window.addEventListener('deviceorientation', this.onDeviceOrientation);
      }
    }
  }

  onDeviceOrientation = (event) => {
    this.deviceOrientation = {
      alpha: event.alpha, // Z轴旋转
      beta: event.beta,   // X轴旋转
      gamma: event.gamma  // Y轴旋转
    };
    this.updateCameraRotation();
  }

  updateCameraRotation() {
    // 将设备方向转换为相机旋转
    this.camera.rotation.set(
      THREE.MathUtils.degToRad(this.deviceOrientation.beta - 90),
      THREE.MathUtils.degToRad(this.deviceOrientation.alpha),
      THREE.MathUtils.degToRad(-this.deviceOrientation.gamma)
    );
  }

  disable() {
    this.enabled = false;
    window.removeEventListener('deviceorientation', this.onDeviceOrientation);
  }
}
```

```javascript
// 热点位置计算（从2D坐标转换为3D坐标）
class HotspotPositionCalculator {
  // 将全景图上的2D坐标转换为球体上的3D坐标
  static convert2Dto3D(x, y, radius = 500) {
    // x, y 为全景图上的百分比坐标 (0-1)
    // 转换为球面坐标

    const phi = (1 - y) * Math.PI;      // 垂直角度 (0-π)
    const theta = x * 2 * Math.PI;       // 水平角度 (0-2π)

    // 球面坐标转换为笛卡尔坐标
    const position = new THREE.Vector3(
      -radius * Math.sin(phi) * Math.cos(theta),
      radius * Math.cos(phi),
      radius * Math.sin(phi) * Math.sin(theta)
    );

    return position;
  }

  // 将3D坐标转换为屏幕坐标（用于热点点击检测）
  static convert3DtoScreen(position, camera, width, height) {
    const vector = position.clone();
    vector.project(camera);

    return {
      x: (vector.x + 1) / 2 * width,
      y: (-vector.y + 1) / 2 * height
    };
  }

  // 检测热点是否在视野内
  static isHotspotVisible(hotspotPosition, camera) {
    const direction = new THREE.Vector3();
    camera.getWorldDirection(direction);

    const hotspotDirection = hotspotPosition.clone().normalize();
    const dot = direction.dot(hotspotDirection);

    // 热点在视野内（前方半球）
    return dot > 0;
  }
}
```

- 一个 `house_vr` 可承载一个户型下的多空间全景场景，例如客厅、卧室1、卧室2、走廊1、厨房、卫生间。

- 热点目标优先使用 `targetSceneId`，也可兼容 `targetSceneCode/targetScene/sceneId/sceneCode`。

- 后端管理需要在保存时校验场景引用关系，避免热点指向不存在的卧室/走廊等场景。

##### 5.5.10.6 文件上传Service实现

```java
@Service
public class FileService {
    
    @Value("${file.local.enabled}")
    private boolean localEnabled;
    
    @Value("${file.local.base-path}")
    private String basePath;
    
    public FileUploadResult upload(MultipartFile file, String category) {
        // 1. 校验文件类型和大小
        validateFile(file, category);
        
        // 2. 生成存储路径
        String fileName = generateFileName(file.getOriginalFilename());
        String relativePath = category + "/" + DateUtil.format(new Date(), "yyyy/MM");
        String fullPath = basePath + "/" + relativePath + "/" + fileName;
        
        // 3. 存储文件
        if (localEnabled) {
            saveToLocal(file, fullPath);
        } else {
            uploadToOSS(file, relativePath, fileName);
        }
        
        // 4. 保存记录
        SysFile sysFile = new SysFile();
        sysFile.setFileName(file.getOriginalFilename());
        sysFile.setFilePath(fullPath);
        sysFile.setFileUrl(getAccessUrl(relativePath, fileName));
        sysFile.setFileSize(file.getSize());
        sysFile.setFileType(file.getContentType());
        sysFile.setFileExt(FilenameUtils.getExtension(file.getOriginalFilename()));
        sysFile.setCategory(category);
        sysFileMapper.insert(sysFile);
        
        return new FileUploadResult(sysFile);
    }
}
```

```java
// 数据层权限拦截
@Bean
public DataPermissionHandler dataPermissionHandler() {
    return new DataPermissionHandler() {
        @Override
        public Expression getExpression(Long userId, String roleCode) {
            if ("SUPER_ADMIN".equals(roleCode)) {
                return null; // 无限制
            }
            // 非私密数据
            return new Equals<>(new SqlItem("is_private"), 0);
        }
    };
}
```

### 7.3 部署步骤

#### 7.3.1 后端部署

```bash
# 1. 打包
mvn clean package -DskipTests

# 2. 上传jar包

# 3. 启动
```

#### 7.3.2 前端部署

```bash

# 3. 上传至Nginx
```

```nginx
server {
```
